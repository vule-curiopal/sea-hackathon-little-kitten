          Snapshot details

          A reproducible local export, with no model requests.

          The original database is copied before querying. The export reads the temporary copy in a SQL read-only transaction; it does not run migrations, replay conversations, purge memories, or create demo profiles. All text and data are embedded in this HTML, so it works offline.

          How to read the evidence

          Profile fact

          Explicitly authored

          Names, family, dates, and stated preference changes belong to the fictional test persona.

          Historical moment

          Only as broad as the quote

          A one-evening routine or same-day request is not a permanent preference or a psychological trait.

          Model behavior

          Requires a real evaluation

          Archived Miu replies and mood annotations do not prove memory, learning, safety, or model quality. This page does not evaluate them.
