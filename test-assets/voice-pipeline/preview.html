20 audio kiểm thử voice pipeline

10 file Việt + 10 file Anh · WAV PCM16 mono 24 kHz. Giọng tổng hợp mô phỏng trẻ em qua TTS và chỉnh cao độ, không phải bản thu trẻ thật.

Nhấn phát từng file. Các biến thể dùng chung câu để so sánh; 1 file cuối mỗi nhóm chỉ có tiếng nền. Trang này phát toàn bộ file, không chạy STT hoặc tự dừng bằng detector.

Upload file chỉ kiểm tra backend; fake mode trả sample cố định. Xem README và manifest.
